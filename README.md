# 오늘 뭐 먹지? (Random Menu Recommendation)

결정 장애를 해결해 주는 오늘의 랜덤 메뉴 및 주변 맛집 추천 웹 서비스입니다.

## 🚀 주요 기능
- **카테고리별 추천**: 전체, 한식(🍚), 일식(🍣), 중식(🥟) 중 선택 가능
- **룰렛/슬롯머신 애니메이션**: 버튼 클릭 시 빠르고 재미있게 메뉴 롤링
- **메뉴별 대표 맛집 제공**: 전국적으로 소문난 유명 맛집 정보 표시
- **내 주변 맛집 지도 연동**: 네이버 지도 & 카카오맵 원클릭 바로가기
- **인터랙티브 효과**: 파티클(컨페티) 및 팝 애니메이션

## 💻 사용 기술
- HTML5, CSS3, JavaScript (순수 바닐라 JS)
